### ⚡ Core Engineering Competencies

- 🤖 **RAG & GenAI Solutions**: Designing Retrieval-Augmented Generation pipelines using embedding models and vector databases to enable accurate, hallucination-free document interrogation.
- 📄 **OCR & Document Processing**: Building intelligent OCR pipelines to parse, extract, and clean unstructured text from scanned contracts, invoices, and documents.
- 🕷️ **Web Scraping & Real Estate Automation**: Developing scalable, anti-detect crawlers for multi-source real estate platforms, managing proxy rotation, CAPTCHA handling, and structured data warehousing.
- ⚙️ **High-Performance APIs & Microservices**: Architecting asynchronous, robust endpoints using **FastAPI**, **Django REST Framework**, and **Flask** with PostgreSQL & Redis.
